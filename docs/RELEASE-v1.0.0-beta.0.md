## Fairy · H.D.D Skin 1.0.0-beta.0

首个公开 beta。纯客户端换皮，host 半边只读，不写文件、不碰凭据、不发外部请求。

### 这一版有什么

**空态 HDD 球**
- 自抠透明 PNG 直接出图（不再拼接 logo 层），线框统一灰蓝、周边自消隐。
- 位置按输入框卡片尺寸自算，换窗口尺寸不漂；三个装饰点稳定沉在输入框上沿以下 6px。
- 新增**镜面倒影层**：铺在输入框下方、文案块下面，`scaleX(-1)` 镜像，`--fairy-refl-lift` 调高低、`opacity` 调浓淡。

**文案带**
- 英文影子（68px / 10% 白）压在中文主标题（54px 斜体）后面，下面接状态行「● 在线 · {时段}，传奇绳匠【法厄同】」。
- 三行同一轴居中；问候语跟系统时间走。

**侧栏**
- 品牌位换成 Fairy H.D.D 眼徽；收起/展开不再闪出官方品牌。
- 工作区角标三态：当前激活红星 / 有任务在跑黄圈 `#f8de2b` / 7 天没动灰圈。

**其它**
- 状态眼五态（idle / thinking / working / done / error）跟会话事件流同步。
- 输入框与页签 2px 灰描边胶囊；模式四档配色：PTC 紫 `#8b7bff` / 标准 橙黄 `#ffab1f` / 创造 红橙 `#ff5a3c` / 极简 绿 `#7bd85a`。

### 安装

```
dsh plugin --profile <profile> add fairy-dsh-skin
```

或下载本页的 `.tgz` 用 `dsh plugin add ./fairy-dsh-skin-1.0.0-beta.0.tgz`。装完重启 DSH（客户端 HMR 有时不够）。

### 已知限制

- 右侧边栏是独立 BrowserView，壁纸穿透不生效。
- 壁纸与斜纹层依赖本地 9335 媒体服务（`lib/wallpaper-server.mjs`），没起就只有纯色背景。
- 工作区「进行中」是按会话行文字判的，宿主改文案会漏判。
- 宿主大版本改类名时，命中不到的选择器会静默失效（预期行为，不会白屏）。

### 已知问题

- 面板/菜单里若有原生控件未换皮，是宿主 DOM 结构变了，欢迎开 issue 附截图。
